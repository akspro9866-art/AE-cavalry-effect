# Testing & Verification Guide

This document specifies the five-tier testing and verification framework governing `ae-effects-cavalry`.

---

## 1. The 5-Tier Verification Framework

To guarantee mathematical correctness, GPU stability, and cross-platform reliability, every effect must pass through five rigorous verification tiers:

```
┌────────────────────────────────────────────────────────────────────────┐
│                      Tier 5: Visual Parity                             │
│   Statistical metrics (MAE, MSE, PSNR, SSIM, Sobel) vs. AE Renders     │
├────────────────────────────────────────────────────────────────────────┤
│                      Tier 4: Live Cavalry 2.8 Runtime                  │
│   Real-time execution on 127.0.0.1:8080, GPU compilation, PNG capture │
├────────────────────────────────────────────────────────────────────────┤
│                      Tier 3: Headless Mock Stallion                    │
│   Node.js VM sandbox, dynamic attribute slots, fault injection         │
├────────────────────────────────────────────────────────────────────────┤
│                      Tier 2: Mathematical Invariants                   │
│   Pure function unit tests, conservation of energy, boundary limits   │
├────────────────────────────────────────────────────────────────────────┤
│                      Tier 1: Static Validation                         │
│   Schema validation, SkSL bracket checks, embedded code synchronization│
└────────────────────────────────────────────────────────────────────────┘
```

---

## 2. Tier Details & Execution

### Tier 1: Static Validation
- **What it checks**:
  - `parameter-map.json` adheres to the registry schema.
  - Every registered SkSL shader (`test/sksl-validation.test.mjs`) has balanced delimiters (comment-aware), a `half4 main` entry point, constant loop bounds (GPU hang safety), no `uniform int`, no redeclaration of the built-in `resolution`, and — per a live-verified Cavalry 2.8 constraint — `layer` as the **only** `uniform shader` input (a second shader uniform compiles but never binds).
  - Dynamic uniforms map 1:1 onto `PARAM_SPECS` in each `implementation.js`.
  - Embedded shader strings in `implementation.js` match the standalone `.sksl` files byte-for-byte.
- **Run command**:
  ```bash
  npm run check    # embedded/agent/script synchronization
  npm test         # includes test/sksl-validation.test.mjs (structural SkSL rules)
  ```

### Tier 2: Mathematical Invariants
- **What it checks**:
  - Analytical correctness of core graphics algorithms.
  - Kernel weight normalization for blur and glow: the unnormalized weight sum $\sum w_i$ is finite and monotone, and the shaders divide the accumulation by it ($c' = \sum w_i c_i / \sum w_i$), which is what preserves energy.
  - Boundary limits: behaviour at $\sigma \to 0$, extreme angles ($360^\circ \equiv 0^\circ$), negative coordinates.
  - Color space conversions (ITU-R Rec. 601 luminance coefficients: $0.299 + 0.587 + 0.114 = 1.0$).
- **Run command**:
  ```bash
  node --test test/**/*.test.mjs
  ```

### Tier 3: Headless Mock Stallion Execution
- **What it checks**:
  - Executes effect applicators inside an isolated Node.js `vm` context against mock Cavalry `api` surfaces: the shared harness in `test/lib/mock-cavalry.mjs` for per-effect tests, and the vendored **Stallion mock server** (`vendor/stallion-mock.mjs`, see `vendor/NOTICE.md`) for full HTTP round-trips including selection, attachment, idempotency, and animation.
  - Validates dynamic attribute provisioning (`api.addDynamic` + `api.renameAttribute`).
  - Tests multi-layer selection, empty selection handling, and reapplication idempotency (updating existing filters without node duplication).
  - Performs **fault injection** (e.g. simulated node creation failures, parenting denials, pre-compose exceptions) to verify that structured error reports are produced without crashing.
  - A dedicated smoke test (`test/bundled-runners.test.mjs`) executes **every runner in the generated panel** against a permissive mock, so a generator or applicator regression cannot ship silently.
- **Run command**:
  ```bash
  npm test
  ```
  The Stallion mock is vendored, so Tier 3 runs identically on every machine and in CI — no external checkout, no silent skips.

### Tier 4: Live Cavalry 2.8 Runtime Verification
- **What it checks**:
  - Communicates directly with a running instance of Cavalry 2.8 via its HTTP bridge endpoint (`http://127.0.0.1:8080`).
  - Creates real geometric shapes, applies the effect, and verifies GPU SkSL compilation on real graphics hardware.
  - Renders a live viewport frame and captures raw PNG bytes.
  - Validates PNG file header integrity (`89 50 4E 47 0D 0A 1A 0A`).
- **Run command**:
  ```bash
  npm run test:live
  ```

### Tier 5: Visual Parity & Diff Analysis
- **What it checks**:
  - Compares live rendered frames against reference frames generated by Adobe After Effects.
  - Built on a zero-dependency, pure-Node.js PNG decoder (`scripts/lib/visual-diff.mjs`) with round-trip and real-artifact decode coverage in `test/visual-diff.test.mjs`.
  - Calculates rigorous mathematical differences:
    - **MAE** (Mean Absolute Error): Average per-pixel color channel deviation.
    - **MSE** (Mean Squared Error): Squared difference penalizing localized spikes.
    - **PSNR** (Peak Signal-to-Noise Ratio): Logarithmic fidelity metric.
    - **SSIM** (Structural Similarity Index): 8×8 windowed SSIM over the Rec. 601 luma plane (global fallback below one window).
    - **Sobel Edge Deviation**: MAE between Sobel gradient-magnitude maps (high-frequency/structural divergence).
- **Parity Reporting Rule**:
  Where authentic After Effects reference renders are not available in `references/ae-renders/`, the test reports parity transparently as **unverified**. No false 100% claims are tolerated.

## 3. Visual Diff Framework (`scripts/lib/visual-diff.mjs`)

The visual diff framework requires zero third-party packages and is fully self-contained:

```javascript
import { decodePng, compareImages, verifyVisualParity } from './scripts/lib/visual-diff.mjs';

const liveImage = decodePng(fs.readFileSync('live.png'));
const referenceImage = decodePng(fs.readFileSync('reference.png'));
const metrics = compareImages(liveImage, referenceImage);
console.log(`PSNR: ${metrics.psnr.toFixed(2)} dB | SSIM: ${metrics.ssim.toFixed(4)} | Sobel: ${metrics.sobelEdgeDeviation.toFixed(3)}`);
```

### Metrics & Passing Thresholds (defaults used by `verifyVisualParity`)

| Metric | Default Threshold | Description |
| :--- | :--- | :--- |
| **MAE** | $\le 5.0$ (on the 0–255 channel scale) | Mean per-channel color divergence |
| **PSNR** | $\ge 30.0\text{ dB}$ | Signal-to-noise ratio |
| **SSIM** | $\ge 0.92$ | Windowed structural luminance/contrast preservation |

All thresholds are overridable through the `thresholds` option (`maxMae`, `minPsnr`, `minSsim`). `sobelEdgeDeviation`, `alphaDeviation`, `colorDeviation`, and `maxPixelDiff` are reported for diagnostics and downstream tooling.
