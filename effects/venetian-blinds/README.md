# Venetian Blinds (ADBE Venetian Blinds) for Cavalry 2.8+

Mathematically reconstructed Adobe After Effects **Venetian Blinds** transition effect implemented as a GPU SkSL filter (`skslFilter`) in Cavalry 2.8+.

## Features
- **Periodic Strip Wipe**: Linear progressive transition with adjustable strip width.
- **Directional Angle**: Smooth angular rotation to wipe vertically, horizontally, or diagonally.
- **Edge Feathering**: Smoothstep boundary gradient across wiping blind edges.
- **Premultiplied Alpha Preservation**: Transparent regions remain transparent without dark halos.
