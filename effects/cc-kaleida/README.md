# CC Kaleida (CC Kaleida) for Cavalry 2.8+

Mathematically reconstructed Adobe After Effects **CC Kaleida** effect implemented as a GPU SkSL filter (`skslFilter`) in Cavalry 2.8+.

## Features
- **Radial Symmetry Segments**: Configurable segment count (Triangle, Hexagon, Octagon, etc.).
- **Seamless Bilateral Reflection**: C0 and C1 boundary matching eliminates visible seams across segment divisions.
- **Center, Size & Rotation**: Independent geometric origin, angular rotation, and radial zoom controls.
- **Full Keyframeability**: All dynamic attributes exposed in Cavalry's Attribute Editor.
