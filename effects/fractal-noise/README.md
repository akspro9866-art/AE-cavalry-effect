# Fractal Noise (After Effects Replication for Cavalry 2.8+)

Reconstructs the industry-standard Adobe After Effects **Fractal Noise** generator as a GPU-accelerated SkSL Filter (`skslFilter`) in Cavalry 2.8+.

## Features

- **Procedural 4D Simplex Fractal**: Infinite resolution, mathematically generated procedural textures.
- **Fractal Types**: Basic, Turbulent Smooth, Turbulent Basic, Dynamic.
- **Contrast, Brightness & Invert**: Complete dynamic range control with Overflow options (Clip, Soft Clamp, Wrap).
- **Evolution & Seamless Cycling**: Drive organic fluid-like evolution with 4D torus looping (`Cycle Evolution`).
- **Dynamic Controls**: 14 editable parameters in the Cavalry Attribute Editor.

## Usage

1. Select any shape, group, or layer in Cavalry.
2. Go to **Scripts -> AE Effects**.
3. Click **Fractal Noise**.
